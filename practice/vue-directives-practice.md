# Практическое задание: Директивы в Vue 3

## Задание 1: v-if и v-show
Создайте компонент с двумя элементами, один из которых отображается с помощью v-if, другой с помощью v-show. Добавьте кнопку для переключения.

## Задание 2: v-for
Создайте список пользователей с помощью v-for. Добавьте возможность фильтрации и сортировки списка.

## Задание 3: v-bind
Создайте компонент с динамическими атрибутами элементов (class, style, src и т.д.) с использованием v-bind.

## Задание 4: v-model
Создайте форму с различными типами полей (input, textarea, select) и двусторонним связыванием через v-model.

## Задание 5: Пользовательские директивы
