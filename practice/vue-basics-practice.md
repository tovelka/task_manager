# Практическое задание: Основы Vue 3

## Задание 1: Создание первого приложения Vue
Создайте простое Vue-приложение с использованием CDN. Отобразите приветственное сообщение и переменную с именем пользователя.

## Задание 2: Двустороннее связывание данных
Создайте форму с текстовым полем, которое связывается с данными через v-model. Добавьте отображение введенного текста под формой.

## Задание 3: Условная отрисовка
Создайте компонент с кнопкой переключения. При нажатии кнопки отображается разный контент (например, "Привет" и "Пока").

## Задание 4: Отображение списков
Создайте список задач, который отображается с помощью v-for. Добавьте возможность добавления и удаления задач.

## Задание 5: Обработка событий
Создайте компонент с кнопкой, которая меняет текст при клике. Добавьте обработку других событий (например, нажатие клавиши).
