# Практическое задание: Composition API в Vue 3

## Задание 1: Создание компонента с Composition API
Создайте компонент, используя Composition API. Компонент должен содержать:
- Данные (ref и reactive)
- Вычисляемые свойства (computed)
- Методы (methods)
- Хуки жизненного цикла (onMounted, onUnmounted)

## Задание 2: Пользовательские хуки
Создайте пользовательский хук для работы с localStorage. Хук должен включать функции для сохранения и получения данных из localStorage.

## Задание 3: Композиционные функции
Создайте композиционную функцию для получения данных из API. Используйте `fetch` или `axios`.

## Задание 4: Передача данных между компонентами
Реализуйте передачу данных между родительским и дочерним компонентом с использованием Composition API.

## Задание 5: Условная логика с реактивностью
