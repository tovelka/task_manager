# События в Vue.js

## Что такое события?

События - это реакции на действия пользователя или другие события в приложении. В Vue.js события обрабатываются с помощью директив и методов компонентов.

## Основные директивы событий

### 1. v-on (или @)

```html
<!-- Полная запись -->
<button v-on:click="handleClick">Кликни меня</button>

<!-- Краткая запись -->
<button @click="handleClick">Кликни меня</button>

<!-- Обработка событий с параметрами -->
<button @click="handleClick(message)">Кликни меня</button>

<!-- Модификаторы событий -->
<button @click.stop="handleClick">Остановить всплытие</button>
<button @click.prevent="handleClick">Отменить действие по умолчанию</button>
<button @keyup.enter="handleSubmit">Нажатие Enter</button>
```

## Обработка событий

### События мыши

```html
<!-- Клик -->
<div @click="handleClick">Кликни меня</div>

<!-- Двойной клик -->
<div @dblclick="handleDoubleClick">Двойной клик</div>

<!-- Наведение мыши -->
<div @mouseenter="handleMouseEnter">Наведи мышь</div>
<div @mouseleave="handleMouseLeave">Убери мышь</div>
```

### События клавиатуры

```html
<!-- Обработка нажатий клавиш -->
<input @keyup="handleKeyup" />

<!-- Специфические клавиши -->
<input @keyup.enter="handleSubmit" />
<input @keyup.esc="handleEsc" />
<input @keyup.space="handleSpace" />
```

### События форм

```html
<!-- Отправка формы -->
<form @submit="handleSubmit">
  <input type="text" name="username" />
  <button type="submit">Отправить</button>
</form>

<!-- Изменение значения поля -->
<input @input="handleInput" />
```

## Задание для самостоятельной работы

Создайте интерактивную игру "Угадай число":

1. Создайте приложение с полем ввода числа и кнопкой "Проверить"
2. Реализуйте логику игры: компьютер генерирует случайное число от 1 до 100
3. Пользователь вводит число и получает подсказку: "Больше", "Меньше" или "Угадал!"
4. Добавьте возможность начать новую игру
5. Реализуйте обработку событий:
   - Нажатие кнопки "Проверить"
   - Ввод числа с клавиатуры (Enter)
   - Нажатие кнопки "Новая игра"

Используйте директивы @click, @keyup и v-model для реализации взаимодействия.
