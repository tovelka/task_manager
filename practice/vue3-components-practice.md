# Практическое задание: Компоненты в Vue 3

## Задание 1: Создание базового компонента
Создайте базовый компонент с использованием Composition API. Компонент должен содержать данные, методы и шаблон.

## Задание 2: Props
Создайте родительский компонент и дочерний компонент. Реализуйте передачу данных через props. Покажите разные типы пропсов и их валидацию.

## Задание 3: События (Emits)
Создайте компонент, который генерирует события с помощью `emit`. Реализуйте взаимодействие между родительским и дочерним компонентом через события.

## Задание 4: Slots
Создайте компонент с использованием слотов (slots). Реализуйте named slots и default slot.

## Задание 5: Компоненты высшего порядка
Создайте компонент, который принимает другой компонент как prop. Покажите использование render-функций или компонентов с использованием `defineComponent`.
