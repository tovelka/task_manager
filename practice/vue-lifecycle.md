"# Жизненный цикл компонента Vue.js\n\n## Что такое жизненный цикл?\n\nЖизненный цикл компонента - это последовательность событий, которые происходят с компонентом от его создания до уничтожения. Понимание жизненного цикла важно для правильной работы с компонентами и управления ресурсами.\n\n## Этапы жизненного цикла\n\n### 1. Инициализация\n\nНа этом этапе компонент создается и готовится к работе:\n\n```javascript\nconst MyComponent = {\n  // Вызывается до создания экземпляра компонента\n  beforeCreate() {\n    console.log('beforeCreate');\n    // Доступ к this, но данные и методы еще не инициализированы\n  },\n  \n  created() {\n    console.log('created');\n    // Данные и методы уже инициализированы\n    // Можно выполнять асинхронные операции\n  }\n}\n```\n\n### 2. Монтирование (Mounting)\n\n```javascript\nconst MyComponent = {\n  beforeMount() {\n    console.log('beforeMount');\n    // Шаблон еще не примонтирован к DOM\n  },\n  \n  mounted() {\n    console.log('mounted');\n    // Компонент уже примонтирован к DOM\n    // Можно работать с DOM элементами\n  }\n}\n```\n\n### 3. Обновление (Updating)\n\n```javascript\nconst MyComponent = {\n  beforeUpdate() {\n    console.log('beforeUpdate');\n    // Данные обновились, но DOM еще не обновлен\n  },\n  \n  updated() {\n    console.log('updated');\n    // DOM обновлен в соответствии с новыми данными\n  }\n}\n```\n\n### 4. Уничтожение (Unmounting)\n\n```javascript\nconst MyComponent = {\n  beforeUnmount() {\n    console.log('beforeUnmount');\n    // Компонент будет уничтожен\n    // Можно очищать ресурсы\n  },\n  \n  unmounted() {\n    console.log('unmounted');\n    // Компонент уничтожен\n  }\n}\n```\n\n## Практические задания\n\n1. Создайте компонент, который выводит время последнего обновления\n2. Реализуйте отслеживание жизненного цикла с помощью console.log на каждом этапе\n3. Добавьте очистку таймеров в beforeUnmount\n\n## Задание для самостоятельной работы\n\nСоздайте приложение-таймер с возможностью запуска, остановки и сброса:\n\n1. Используйте методы жизненного цикла для управления таймерами:\n   - created() для инициализации таймера\n   - beforeUnmount() для очистки таймера при удалении компонента\n\n2. Реализуйте следующую функциональность:\n   - Отображение текущего времени в формате HH:MM:SS\n   - Кнопка \"Старт\" для запуска таймера\n   - Кнопка \"Стоп\" для остановки таймера\n   - Кнопка \"Сброс\" для сброса времени\n   - Отображение времени последнего обновления\n\n3. Проверьте работу методов жизненного цикла при создании и удалении компонента\n\nИспользуйте методы: created, beforeUnmount, mounted для реализации функциональности.\n</ARG>
