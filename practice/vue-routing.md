"# Маршрутизация в Vue.js\n\n## Что такое маршрутизация?\n\nМаршрутизация - это механизм, который позволяет организовать навигацию между разными страницами или состояниями приложения. В Vue.js для этого используется библиотека vue-router.\n\n## Основы настройки маршрутов\n\n### 1. Установка vue-router\n\n```bash\nnpm install vue-router@4\n```\n\n### 2. Создание маршрутов\n\n```javascript\nimport { createRouter, createWebHistory } from 'vue-router'\n\nconst routes = [\n  {\n    path: '/',\n    name: 'Home',\n    component: Home\n  },\n  {\n    path: '/about',\n    name: 'About',\n    component: About\n  }\n]\n\nconst router = createRouter({\n  history: createWebHistory(),\n  routes\n})\n\nexport default router\n```\n\n### 3. Подключение маршрутизатора\n\n```javascript\nimport { createApp } from 'vue'\nimport App from './App.vue'\nimport router from './router'\n\nconst app = createApp(App)\napp.use(router)\napp.mount('#app')\n```\n\n## Использование маршрутов в шаблоне\n\n```html\n<template>\n  <div id=\"app\">\n    <nav>\n      <router-link to=\"/\">Главная</router-link>\n      <router-link to=\"/about\">О нас</router-link>\n    </nav>\n    \n    <router-view></router-view>\n  </div>\n</template>\n```\n\n## Параметры маршрутов\n\n```javascript\nconst routes = [\n  {\n    path: '/user/:id',\n    name: 'User',\n    component: User\n  }\n]\n```\n\n```html\n<router-link :to=\"`/user/${userId}`\">Пользователь</router-link>\n```\n\n## Практические задания\n\n1. Создайте приложение с тремя страницами: Главная, О нас, Контакты\n2. Добавьте навигационное меню между страницами\n3. Реализуйте маршруты с параметрами (например, страница пользователя)\n\n## Задание для самостоятельной работы\n\nСоздайте приложение-каталог пользователей:\n\n1.
