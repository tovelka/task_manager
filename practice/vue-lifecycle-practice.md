# Практическое задание: Жизненный цикл компонентов в Vue 3

## Задание 1: Хуки жизненного цикла
Создайте компонент с использованием всех основных хуков жизненного цикла (created, mounted, updated, unmounted).

## Задание 2: Асинхронные операции
Реализуйте асинхронную загрузку данных в хуке mounted и обработку ошибок.

## Задание 3: Очистка ресурсов
Создайте компонент с таймерами или подписками, которые очищаются в хуке unmounted.

## Задание 4: Перезапуск компонента
Создайте компонент, который можно пересоздавать с помощью key и покажите работу хуков при этом.

## Задание 5: Условная отрисовка
