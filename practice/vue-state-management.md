"# Управление состоянием в Vue.js\n\n## Что такое управление состоянием?\n\nУправление состоянием - это подход к организации данных в приложении, который позволяет эффективно управлять данными и их изменением. В больших приложениях важно правильно организовать состояние для предотвращения проблем с синхронизацией данных.\n\n## Основные принципы управления состоянием\n\n### 1. Централизованное хранение\n\nВсе данные приложения хранятся в одном месте (store), что упрощает отладку и понимание потока данных:\n\n```javascript\n// Пример простого store\nconst store = {\n  state: {\n    count: 0,\n    user: null\n  },\n  \n  mutations: {\n    increment(state) {\n      state.count++\n    },\n    setUser(state, user) {\n      state.user = user\n    }\n  },\n  \n  actions: {\n    async fetchUser({ commit }, userId) {\n      const user = await api.getUser(userId)\n      commit('setUser', user)\n    }\n  }\n}\n```\n\n### 2. Взаимодействие с компонентами\n\nКомпоненты взаимодействуют с хранилищем через методы:\n\n```javascript\n// Компонент\nconst MyComponent = {\n  data() {\n    return {\n      localData: 'local'\n    }\n  },\n  \n  computed: {\n    count() {\n      return this.$store.state.count\n    }\n  },\n  \n  methods: {\n    increment() {\n      this.$store.commit('increment')\n    }\n  }\n}\n```\n\n## Pinia (современное решение)\n\nPinia - это современный инструмент управления состоянием для Vue.js:\n\n```javascript\n// store/user.js\nimport { defineStore } from 'pinia'\n\nexport const useUserStore = defineStore('user', {\n  state: () => ({\n    name: '',\n    email: ''\n  }),\n  \n  getters: {\n    isLoggedIn: (state) => state.name !== ''\n  },\n  \n  actions: {\n    login(name, email) {\n      this.name = name\n      this.email = email\n    },\n    \n    logout() {\n      this.name = ''\n      this.email = ''\n    }\n  }\n})\n```\n\n```javascript\n// Использование в компоненте\nimport { useUserStore } from '../stores/user'\n\nexport default {\n  setup() {\n    const userStore = useUserStore()\n    \n    const handleLogin = () => {\n      userStore.login('Иван', 'ivan@example.com')\n    }\n    \n    return {\n      userStore,\n      handleLogin\n    }\n  }\n}\n```\n\n## Практические задания\n\n1.
