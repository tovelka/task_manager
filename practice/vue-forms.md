"# Работа с формами в Vue.js\n\n## Что такое формы?\n\nФормы - это элементы интерфейса, которые позволяют пользователям вводить данные. В Vue.js работа с формами реализуется через двустороннюю привязку данных и обработку событий.\n\n## Основные элементы форм\n\n### 1. Текстовые поля\n\n```html\n<input v-model=\"inputValue\" type=\"text\" placeholder=\"Введите текст\">\n<p>Введенный текст: {{ inputValue }}</p>\n```\n\n### 2. Чекбоксы\n\n```html\n<!-- Один чекбокс -->\n<input type=\"checkbox\" v-model=\"isChecked\" id=\"checkbox\">\n<label for=\"checkbox\">Согласен с условиями</label>\n\n<!-- Несколько чекбоксов -->\n<div v-for=\"option in checkboxOptions\" :key=\"option.value\">\n  <input type=\"checkbox\" v-model=\"selectedOptions\" :value=\"option.value\">\n  <label>{{ option.label }}</label>\n</div>\n```\n\n### 3. Селекты\n\n```html\n<select v-model=\"selectedValue\">\n  <option value=\"\">Выберите значение</option>\n  <option value=\"option1\">Вариант 1</option>\n  <option value=\"option2\">Вариант 2</option>\n</select>\n```\n\n## Валидация форм\n\n### 1. Простая валидация\n\n```javascript\nconst app = Vue.createApp({\n  data() {\n    return {\n      email: '',\n      password: ''\n    }\n  },\n  computed: {\n    isEmailValid() {\n      return this.email.includes('@')\n    },\n    isPasswordValid() {\n      return this.password.length >= 6\n    },\n    isFormValid() {\n      return this.isEmailValid && this.isPasswordValid\n    }\n  }\n})\n```\n\n### 2. Валидация с ошибками\n\n```javascript\nconst app = Vue.createApp({\n  data() {\n    return {\n      email: '',\n      errors: {}\n    }\n  },\n  methods: {\n    validateForm() {\n      this.errors = {}\n      \n      if (!this.email.includes('@')) {\n        this.errors.email = 'Некорректный email'\n      }\n      \n      return Object.keys(this.errors).length === 0\n    }\n  }\n})\n```\n\n## Практические задания\n\n1. Создайте форму регистрации с полями: имя, email, пароль\n2. Добавьте валидацию полей\n3. Реализуйте отображение ошибок валидации\n\n## Задание для самостоятельной работы\n\nСоздайте приложение-калькулятор с формой ввода данных:\n\n1. Создайте форму с полями:\n   - Первое число\n   - Второе число\n   - Операция (сложение, вычитание, умножение, деление)\n\n2. Реализуйте логику калькулятора:\n   - Обработка ввода чисел\n   - Выбор операции\n   - Отображение результата\n   - Валидация ввода (проверка на числа)\n\n3. Добавьте валидацию:\n   - Проверка, что введены числа\n   - Проверка, что выбрана операция\n   - Обработка деления на ноль\n\n4. Используйте двустороннюю привязку данных (v-model) для всех полей формы\n5. Реализуйте отображение ошибок валидации\n6. Добавьте возможность очистки формы\n\nИспользуйте v-model для связывания данных, методы для обработки событий и вычисляемые свойства для валидации.\n</ARG>
