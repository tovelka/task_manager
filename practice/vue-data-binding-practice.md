# Практическое задание: Связывание данных в Vue 3

## Задание 1: Интерполяция данных
Создайте компонент с разными типами данных (строка, число, boolean) и отобразите их с помощью интерполяции {{}}.

## Задание 2: Одностороннее связывание
Создайте компонент с элементом input и кнопкой. При нажатии кнопки значение input меняется через v-bind.

## Задание 3: Двустороннее связывание
Создайте форму с несколькими полями (input, textarea, select) и двусторонним связыванием через v-model.

## Задание 4: Связывание атрибутов
Создайте компонент, который меняет классы и стили элементов с помощью v-bind.

## Задание 5: Связывание событий
