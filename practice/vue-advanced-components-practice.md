# Практическое задание: Продвинутые компоненты в Vue 3

## Задание 1: Компоненты с состоянием
Создайте сложный компонент с внутренним состоянием и управлением через методы.

## Задание 2: Компоненты с динамическими свойствами
Создайте компонент, который может изменять свои свойства в зависимости от входных данных.

## Задание 3: Компоненты с сложной логикой
Реализуйте компонент с комплексной бизнес-логикой и несколькими вычисляемыми свойствами.

## Задание 4: Компоненты с вложенными элементами
Создайте компонент, который может содержать другие компоненты как слоты.

Создайте компонент с оптимизациями производительности (memoization, lazy loading).
