# Привязка данных в Vue.js

## Что такое привязка данных?

Привязка данных - это механизм, который позволяет автоматически синхронизировать данные приложения с DOM. В Vue.js это реализуется через директивы и реактивную систему.

## Типы привязки данных

### 1. Односторонняя привязка (v-bind)

```html
<!-- Полная запись -->
<div v-bind:id="dynamicId">Содержимое</div>

<!-- Краткая запись -->
<div :id="dynamicId">Содержимое</div>

<!-- Привязка классов -->
<div :class="{ active: isActive, 'text-danger': hasError }">Содержимое</div>

<!-- Привязка стилей -->
<div :style="{ color: textColor, fontSize: fontSize + 'px' }">Содержимое</div>
```

### 2. Двусторонняя привязка (v-model)

```html
<!-- Для текстовых полей -->
<input v-model="message" />

<!-- Для чекбоксов -->
<input type="checkbox" v-model="isChecked" />

<!-- Для радио-кнопок -->
<input type="radio" v-model="picked" value="one" />
<input type="radio" v-model="picked" value="two" />

<!-- Для селектов -->
<select v-model="selected">
  <option value="vue">Vue.js</option>
  <option value="react">React</option>
</select>
```

### 3. Связывание массивов

```html
<!-- Для списков -->
<ul>
  <li v-for="(item, index) in items" :key="index">
    {{ item.name }}
  </li>
</ul>

<!-- Для объектов -->
<div v-for="(value, key, index) in object" :key="key">
  {{ key }}: {{ value }}
</div>
```

## Практические задания

1. Создайте форму с полями: имя, email, возраст, пол
2. Реализуйте двустороннюю привязку данных для всех полей формы
3. Добавьте валидацию полей и отображение ошибок

## Задание для самостоятельной работы

Создайте интерактивную форму регистрации пользователя с полями:
- Имя (текстовое поле)
- Email (текстовое поле)
- Возраст (числовое поле)
- Пол (выбор из радио-кнопок)
- Интересы (чекбоксы для нескольких значений)

Реализуйте следующие функции:
1. Все поля должны быть связаны с данными приложения
2. Отображение текущих значений в реальном времени
3. Валидацию полей (например, email должен содержать @)
4. Сброс формы по нажатию кнопки

Используйте директивы v-model и v-bind для реализации привязки данных.
